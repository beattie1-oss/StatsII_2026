********************************************************************************************************************************
***** Replication instructions for "Can Warm Behavior Mitigate the Negative Effect of Unfavoable Decisions on Citizens' Trust?"
***** in Journal of Experimental Political Science****************************************************************************** 
********************************************************************************************************************************

********************************************************************************************************************************
***** To replicate the analyses in the paper and appendix, download the data set called "data.dta" and the R scripts************
***** called "replication_main_appendix.R" and "replication_mediation.R"********************************************************
***** Remember to set the working directory to the folder containing the data set. Then run the R scripts to replicate results**
********************************************************************************************************************************

********************************
***** Description of files *****
********************************

*** "data.dta" -- the main data set
*** "replication_main_appendix.R" -- R script to produce results in the main article and appendix (excluding the mediation analysis in Appendix F)
*** "replication_mediation.R" -- R script for the mediation analysis presented in Appendix F
*** "Codebook.pdf" -- Description of how key variables used in the analyses are coded
